## 🎮 Featured Game Project

### Last Second

**2D Arcade Survival Prototype · Unity 6 · C#**

Last Second is a fast-paced 2D arcade survival game where players switch between three lanes to dodge incoming obstacles, survive as long as possible, and beat their high score.

**Features**
- Three-lane player movement.
- Random single and double obstacle formations.
- Progressive difficulty based on the player's score.
- Score tracking and persistent high scores.
- Start screen, Game Over screen, retry, and home navigation.
- Sound effects for gameplay events.

**Gameplay & Source Code**

[▶ Watch Gameplay](https://drive.google.com/file/d/1p9fB7mP5t0p3sD54bvvjroyni6mId68k/view?usp=sharing) · [View Source Code](https://github.com/Aliem51/Last-Second-Unity_game)

**Development Notes**

The project focuses on a straightforward gameplay loop, responsive controls, and increasing challenge. During playtesting, I evaluated how obstacle speed and combinations affected the time available for players to react and switch lanes.
